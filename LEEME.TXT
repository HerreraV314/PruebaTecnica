Realizado en

PHP Version 8.0.13
PostgreSQL 18.4 
pgAdmin4 9.5

Pasos para la instalación:
1. Clonar o descargar este repositorio en la carpeta raíz de su servidor web local.
2. Abrir pgAdmin (o su gestor de PostgreSQL preferido) y crear una base de datos, la utilizada en "proceso.php" fue llamada "BASE_DATOS1".
3. Abrir la carpeta "SQL" de este proyecto y ejecutar el archivo "script.sql" dentro de la base de datos recién creada para generar las tablas y los datos iniciales.
4. Asegurarse de revisar las credenciales del archivo "proceso.php", en este se ocupa el puerto 5433 y la contraseña "admin", reemplazar con los de su instalacion de PostgreSQL
5. Abrir el navegador y acceder a la ruta local del proyecto (ej. http://localhost/prueba_tecnica/index.php).
